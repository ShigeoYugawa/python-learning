# Python Learning

Pythonの基礎学習と実践的なプログラミングスキルの習得を目的とした学習プロジェクトです。

## 目的

Pythonの基本文法や標準ライブラリを学習しながら、実際の業務で活用できるファイル操作・データ加工などの処理を実装します。

## 学習環境

- OS: Windows 11
- Python: 3.13
- Editor: Visual Studio Code
- Version Control: Git / GitHub

## プロジェクト構成

```text
PythonLearning/
```

## 学習内容

### FileProcessor

Pythonの標準ライブラリを中心としたファイル操作の学習・実装。

| プロジェクト | 内容 |
|---|---|
| step01_read_text | テキストファイルの読み込み |
| step02_write_text | テキストファイルへの書き込み |
| step03_append_text | テキストファイルへの追記 |
| step04_exclusive_create | ファイルの排他的作成 |
| step05_delete_file | ファイルの削除 |
| step06_csv_read | CSVファイルの読み込み |
| CsvExtractor | CSVデータの抽出・加工 |
